"""
organizar_dados_bdmep.py
=========================

Organização de dados brutos de precipitação do BDMEP/INMET
(Banco de Dados Meteorológicos para Ensino e Pesquisa).

Objetivo: Este código tem, por objetivo, transformar o arquivo CSV bruto exportado pelo BDMEP em um dataset limpo, tabular e pronto para análise exploratória de dados, seguindo um fluxo padrão 
de ciência de dados:
1. Leitura e separação de metadados x dados
2. Parsing e tipagem correta das colunas
3. Tratamento de valores ausentes
4. Validação de integridade da série temporal (datas faltantes)
5. Engenharia de atributos (ano, mês, estação do ano)
6. Geração de estatísticas descritivas (qualidade dos dados)
7. Exportação dos resultados (dataset limpo + resumo anual)

Entrada esperada: Um arquivo .csv exportado pelo BDMEP, com 9 linhas de metadados no topo, uma linha em branco, o cabeçalho da tabela e os dados
separados por ";". 
Exemplo de estrutura:

Nome: ARACAJU
Codigo Estacao: A409
Latitude: -10.9525
Longitude: -37.05444444
Altitude: 3.72
Situacao: Pane
Data Inicial: 2016-09-03
Data Final: 2026-09-03
Periodicidade da Medicao: Diaria

Data Medicao;PRECIPITACAO TOTAL, DIARIO (AUT)(mm);
2016-09-03;0;
2016-09-04;7.2;
...

Como usar?
    python organizar_dados_bdmep.py caminho/para/arquivo_bruto.csv

Saídas geradas (na mesma pasta do script, dentro de "output/"):
    - dados_limpos.csv        -> série diária tratada
    - resumo_anual.csv        -> resumo de qualidade/estatísticas por ano
    - metadados.json          -> metadados da estação extraídos do cabeçalho
"""
